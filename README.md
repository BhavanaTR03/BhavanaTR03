## 🚀 Featured projects

### 🧠 [LLM Safety Constraint Comparison](https://github.com/BhavanaTR03/llm-safety-constraint-comparison) *(MSc dissertation)*
Compares three ways of constraining generative AI outputs: **prompt engineering, keyword-based filtering and LLM-based classification**.
`Python` `LLMs` `Prompt engineering` `Evaluation`

### 🎫 [NLP Support Ticket Classification](https://github.com/BhavanaTR03/nlp-support-ticket-classification)
Text classification pipeline that sorts **308 support tickets into 14 categories**. Compared stemming vs lemmatisation preprocessing with TF-IDF features and Logistic Regression, reaching a **macro-F1 of 0.90** against a 0.87 baseline.
`Python` `Scikit-learn` `TF-IDF` `NLP`

### 🛒 Tesco Clubcard: Nutrient Diversity in London
Analysed purchasing data for **~1.6M households across 983 London areas (MSOAs)** and 30+ nutrients. Used **Shannon Entropy**, regression and geospatial analysis to measure nutrient diversity, then presented findings to a non-technical academic panel via Power BI.
`Python` `GIS` `Power BI` `Statistics`

### 💬 [Social Media Sentiment Analysis](https://github.com/BhavanaTR03/Sentiment-analysis-social-media)
Python project analysing sentiment in social media comments.
`Python` `NLP`
